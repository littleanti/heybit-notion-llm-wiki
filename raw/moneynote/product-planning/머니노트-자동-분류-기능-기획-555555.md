## 요약
머니노트 거래내역 자동 분류 정확도를 92%까지 올리기 위한 분류기 개편 기획이다.
2026년 3월 기준 정확도는 88%이며, 오분류가 몰리는 항목은 계좌 간 이체, 현금 인출, 정기결제 세 종류다.
규칙 기반 매칭에 사용자 수정 이력을 결합해 개인화 규칙을 만드는 구조를 도입한다.
## 배경 · 문제
- 사용자가 카테고리를 직접 고치는 비율이 전체 거래의 11%다.
- 가맹점명이 축약되어 들어오는 은행이 있어 규칙 매칭이 실패한다.
- 오분류가 쌓이면 예산 리포트 신뢰도가 떨어져 프리미엄 해지 사유로 이어진다.

## 범위 (포함 / 제외)
- 포함: 카드 승인 내역, 계좌 입출금, 정기결제 인식
- 포함: 사용자 수정 이력을 반영한 개인 규칙 저장
- 제외: 사용자가 손으로 적는 현금 지출 입력 건
- 제외: 해외 통화 거래. 환율 처리가 필요해 별도 기획으로 분리한다.
## 상세
1. 가맹점명 정규화 사전을 만들고 은행별 축약 패턴을 등록한다.
2. 규칙 매칭이 실패한 건만 통계 모델로 넘겨 2단계로 판정한다.
3. 사용자가 카테고리를 고치면 해당 가맹점에 개인 규칙을 저장한다.
4. 주 1회 배치로 전체 정확도를 측정해 내부 대시보드에 기록한다.

- 스크래핑 방식 은행은 가맹점명 필드가 비어 오는 경우가 있어 정확도 집계를 따로 나눈다.
- 개인 규칙이 늘어나면 분류 지연이 커질 수 있어 사용자당 규칙 수 상한을 둔다.
## 미확정 · 열린 질문
- 개인 규칙과 전역 규칙이 충돌할 때 어느 쪽을 우선할지 정하지 못했다.
- 정확도 측정 대상 기간을 최근 30일로 볼지 90일로 볼지 확정하지 않았다.
