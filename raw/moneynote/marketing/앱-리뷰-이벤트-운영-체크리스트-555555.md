## 요약
앱 리뷰 이벤트를 운영할 때 확인하는 체크리스트다.
스토어 정책에 걸릴 수 있는 표현을 걸러내는 항목과 개인정보 처리 항목을 함께 넣었다.
2026년 6월 운영 결과를 반영해 항목을 정리했다.
## 준비
- [x] 이벤트 기간과 참여 조건을 확정한다.
- [x] 리뷰 작성 강요로 읽히는 문구를 뺀다. 별점 조건은 넣지 않는다.
- [x] 경품 예산과 지급 방식을 확정한다. 6월 이벤트는 총 3,000,000원 규모였다.
- [x] 법무 확인을 받는다. 담당은 정수아다.
- [ ] 당첨자 개인정보 수집 항목을 최소화한다. 이름과 연락처만 받는다.
## 운영 중
- [x] 이벤트 배너 노출 상태를 매일 1회 확인한다.
- [x] 참여 문의는 하루 단위로 CS 응대 목록에 넘긴다.
- [ ] 중복 참여 계정을 주 1회 점검한다.
- [ ] 부정 참여가 확인되면 당첨 대상에서 빼고 기록을 남긴다.
## 마감 후
- [x] 당첨자를 발표하고 경품을 7일 안에 지급한다.
- [ ] 수집한 개인정보를 지급 완료 후 30일 안에 삭제한다.
- [ ] 결과 요약을 마케팅 주간 회의에 공유한다.
