## 핵심 사실

1. 자동 분류 정확도 목표는 92%다. 2026년 3월 기준 정확도는 88%, 사용자 수동 수정률은 11%이며 목표는 7% 이하다 — [머니노트 자동 분류 기능 기획](../../../raw/moneynote/product-planning/머니노트-자동-분류-기능-기획-555555.md)
2. 오분류가 몰리는 항목은 계좌 간 이체, 현금 인출, 정기결제 세 종류다 — [머니노트 자동 분류 기능 기획](../../../raw/moneynote/product-planning/머니노트-자동-분류-기능-기획-555555.md)
3. 개편 방식은 가맹점명 정규화 사전 + 규칙 매칭 실패 건만 통계 모델로 넘기는 2단계 판정 + 사용자 수정 이력 기반 개인 규칙 저장이다. 전체 정확도는 주 1회 배치로 측정해 내부 대시보드에 기록한다 — [머니노트 자동 분류 기능 기획](../../../raw/moneynote/product-planning/머니노트-자동-분류-기능-기획-555555.md)
4. 범위에서 제외한 것은 사용자가 손으로 적는 현금 지출 입력 건과 해외 통화 거래다. 해외 통화는 환율 처리가 필요해 별도 기획으로 분리했다 — [머니노트 자동 분류 기능 기획](../../../raw/moneynote/product-planning/머니노트-자동-분류-기능-기획-555555.md)
5. 개선 순서는 [은행 연동 지원 목록](../../../raw/moneynote/product-description/은행-연동-지원-목록-555555.md) 의 연동 방식 기준으로 정하고, 스크래핑 방식 은행은 가맹점명 필드가 비어 오는 경우가 있어 정확도 집계를 따로 나눈다 — [머니노트 자동 분류 기능 기획](../../../raw/moneynote/product-planning/머니노트-자동-분류-기능-기획-555555.md)
6. 분류기 개편은 v2.4로 미뤘고 92% 목표는 그대로 뒀다. 2026-09-04 회의 기록이다 (원본 일부 누락) — [9월 릴리스 회의록 (v2.3)](../../../raw/moneynote/product-dev/9월-릴리스-회의록-v2.3-555555.md)

## 진행 중 · 초안

- 예산 알림 기획은 AI가 생성한 초안이며 사람 검토를 받지 않았다. 원본이 "수치와 일정은 확정이 아니다" 라고 밝히고 있다 (초안) — [예산 알림 기획 (AI 초안)](../../../raw/moneynote/product-planning/예산-알림-기획-AI-초안-555555.md)
  - 지표 초안: 예산 설정 사용자의 30일 유지율을 기준 대비 5%p 상향, 알림 수신 후 24시간 내 앱 실행 비율 20%, 알림 차단 비율 10% 이하 (초안)
  - 범위 초안: 카테고리별 예산 80% 도달 알림과 100% 초과 알림, 프리미엄 사용자 10% 대상 베타 노출. 주간 단위 예산과 알림 문구 개인화는 제외 (초안)
  - 동작 초안: 임계값 초과 시 알림 큐에 넣고 같은 카테고리는 하루 1회로 제한, 발송은 매시 정각 이후 5분 구간에 모아 처리 (초안)
  - 원본 callout: 오세린 검토 후 상태를 검토중으로 바꾸고 작성주체를 사람+AI로 고친다 (초안)
- 초안이 근거로 삼은 원본은 2026-09-04 릴리스 회의록의 예산 알림 논의 항목이다. 회의록은 확정이며 "예산 알림 베타는 프리미엄 사용자 10%에게 먼저 노출한다" 와 "예산 알림에는 베타 라벨을 붙인다" 를 결정으로 적었다 (원본 일부 누락) — [9월 릴리스 회의록 (v2.3)](../../../raw/moneynote/product-dev/9월-릴리스-회의록-v2.3-555555.md)
