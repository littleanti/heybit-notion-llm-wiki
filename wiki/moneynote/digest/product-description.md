## 핵심 사실

1. 머니노트는 카드와 계좌 내역을 모아 지출을 자동으로 분류하는 가계부 앱이다. 외부 문의 응대와 스토어 소개문은 이 문서의 표현을 기준으로 쓴다 — [머니노트 서비스 소개](../../../raw/moneynote/product-description/머니노트-서비스-소개-555555.md)
2. 무료 플랜은 계좌 2개까지 연동할 수 있고, 프리미엄은 월 4,900원 또는 연 49,000원이다. 프리미엄으로 바꾸면 연동 계좌 수 제한이 풀리고 월별 리포트가 열린다 — [머니노트 서비스 소개](../../../raw/moneynote/product-description/머니노트-서비스-소개-555555.md)
3. 온보딩 순서는 설치 → 휴대폰 번호 가입 → 은행 선택·인증 → 첫 동기화(최근 3개월 내역 자동 분류) → 카테고리별 예산 설정이다 — [머니노트 서비스 소개](../../../raw/moneynote/product-description/머니노트-서비스-소개-555555.md)
4. 내역 반영에는 최대 15분이 걸린다고 안내한다. 처리 방식은 [거래내역 동기화 파이프라인](../../../raw/moneynote/product-dev/거래내역-동기화-파이프라인-555555.md) 을 따른다 — [은행 연동 지원 목록](../../../raw/moneynote/product-description/은행-연동-지원-목록-555555.md)
5. 결제 후 마음이 바뀐 경우 7일 이내 전액 환불이 가능하다. 기준은 [머니노트 구독 환불 규정](../../../raw/moneynote/legal/머니노트-구독-환불-규정-555555.md) 을 따른다 — [머니노트 서비스 소개](../../../raw/moneynote/product-description/머니노트-서비스-소개-555555.md)
6. 지원 은행은 12개이고 연동 방식은 은행 API와 스크래핑 두 가지다. 목록에서 API 로 표기된 은행은 하늘·바다·숲·달빛·새벽·강변·바람·호수, 스크래핑으로 표기된 은행은 별빛·노을·들녘·구름이다 — [은행 연동 지원 목록](../../../raw/moneynote/product-description/은행-연동-지원-목록-555555.md)
7. 은행별 제약이 응대 문구를 바꾼다. 숲은행 일 호출 한도 4,000회, 달빛은행 가맹점명 축약, 새벽은행 인증 유효기간 90일, 별빛은행 매일 00시~02시 점검, 들녘은행 가맹점명 필드 공백, 강변은행 입출금만 지원 — [은행 연동 지원 목록](../../../raw/moneynote/product-description/은행-연동-지원-목록-555555.md)
8. 목록이 바뀌면 은행 연동 지원 목록을 먼저 고치고 소개문과 응대 문서를 뒤따라 고친다. 목록에 없는 은행은 지원하지 않으며 추가 요청은 개발팀 요청 목록에 남긴다 — [은행 연동 지원 목록](../../../raw/moneynote/product-description/은행-연동-지원-목록-555555.md)

## 진행 중 · 초안

- 이 카테고리의 원본 2건은 모두 확정 상태이며 초안·검토중 문서는 없다 — [머니노트 서비스 소개](../../../raw/moneynote/product-description/머니노트-서비스-소개-555555.md), [은행 연동 지원 목록](../../../raw/moneynote/product-description/은행-연동-지원-목록-555555.md)
