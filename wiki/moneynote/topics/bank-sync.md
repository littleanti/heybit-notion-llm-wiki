## 현재 규칙 · 사실

1. 지원 은행은 12개다. 2026-06-01 바람은행, 2026-08-18 호수은행이 추가됐고 목록 갱신일은 2026-09-02다. 목록에 없는 은행은 지원하지 않으며 추가 요청은 개발팀 요청 목록에 남긴다 — [은행 연동 지원 목록](../../../raw/moneynote/product-description/은행-연동-지원-목록-555555.md)
2. 연동 절차는 앱에서 은행을 고르고 앱 안에서 인증 → 첫 동기화로 최근 3개월 내역 수집 → 이후 15분 간격 자동 동기화다 — [은행 연동 지원 목록](../../../raw/moneynote/product-description/은행-연동-지원-목록-555555.md)
3. 동기화 방식은 15분 간격 폴링으로 결정됐다(2026-04-02 최초 기록, 2026-08-20 갱신). 폴링 결과는 큐에 넣고 분류기가 순서대로 처리해 분류기 지연이 폴링을 막지 않게 한다 — [거래내역 동기화 파이프라인](../../../raw/moneynote/product-dev/거래내역-동기화-파이프라인-555555.md)
4. 실시간 웹훅은 채택하지 않았다. 연동 은행 12개 중 웹훅 제공은 3개뿐이고 규격이 달라 유지 비용이 크다. 지원 은행이 8개를 넘으면 다시 검토한다 — [거래내역 동기화 파이프라인](../../../raw/moneynote/product-dev/거래내역-동기화-파이프라인-555555.md)
5. 2026년 8월 실측 기준 평균 반영 지연은 약 7분, 최대 15분이다 — [거래내역 동기화 파이프라인](../../../raw/moneynote/product-dev/거래내역-동기화-파이프라인-555555.md)
6. 수동 동기화 버튼은 보조 수단이며 5분에 1회로 제한된다. CS 도 같은 제한을 안내한다 — [거래내역 동기화 파이프라인](../../../raw/moneynote/product-dev/거래내역-동기화-파이프라인-555555.md), [은행 연동이 안 돼요 응대](../../../raw/moneynote/cs/은행-연동이-안-돼요-응대-555555.md)
7. 무료 플랜 연동 계좌 수는 2개다. 3개 이상 연동 실패 문의는 플랜 안내로 처리한다 — [머니노트 서비스 소개](../../../raw/moneynote/product-description/머니노트-서비스-소개-555555.md), [은행 연동이 안 돼요 응대](../../../raw/moneynote/cs/은행-연동이-안-돼요-응대-555555.md)
8. 은행별 제약(2026-09-02 기준) — 스크래핑은 별빛·노을·들녘·구름, 나머지는 API 다 — [은행 연동 지원 목록](../../../raw/moneynote/product-description/은행-연동-지원-목록-555555.md)

## 카테고리별 관점

- 상품설명은 목록을 정본으로 둔다. 목록이 바뀌면 이 문서를 먼저 고치고 소개문과 응대 문서를 뒤따라 고친다 — [은행 연동 지원 목록](../../../raw/moneynote/product-description/은행-연동-지원-목록-555555.md)
- 상품개발은 호출량 예측 가능성을 이유로 폴링을 골랐다. 은행별 호출 한도가 달라 호출량을 묶어야 했다 — [거래내역 동기화 파이프라인](../../../raw/moneynote/product-dev/거래내역-동기화-파이프라인-555555.md)
- CS 는 은행명 확인 → 15분 안내 → 수동 동기화 1회 → 스크래핑 은행은 1시간 후 재시도 → 재연동 및 개발팀 전달 순서로 응대한다. 사용자에게 은행 로그인 정보를 묻지 않는다 — [은행 연동이 안 돼요 응대](../../../raw/moneynote/cs/은행-연동이-안-돼요-응대-555555.md)
- 상품기획은 은행별 데이터 품질 차이를 분류 정확도 개선 순서의 기준으로 쓴다. 스크래핑 은행은 가맹점명 필드가 비어 와서 정확도 집계를 따로 나눈다 — [머니노트 자동 분류 기능 기획](../../../raw/moneynote/product-planning/머니노트-자동-분류-기능-기획-555555.md)
- 법무는 연동 확대 시 계좌 추가마다 개별 동의로 분리해야 한다고 보고, 스크래핑 연동(은행 4곳)에 대해 대체 수단 확보 계획을 문서로 남기라고 적었다 (검토중) — [마이데이터 연동 법적 검토](../../../raw/moneynote/legal/마이데이터-연동-법적-검토-555555.md)
- 마케팅·상품개발 접점으로, 2026-09-04 회의에서 추석 프로모션 유입 문의 증가에 따라 연동 응대 문구를 먼저 갱신하기로 논의했다 (원본 일부 누락) — [9월 릴리스 회의록 (v2.3)](../../../raw/moneynote/product-dev/9월-릴리스-회의록-v2.3-555555.md)
