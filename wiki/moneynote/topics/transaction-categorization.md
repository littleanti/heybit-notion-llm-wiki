## 현재 규칙 · 사실

1. 목표 지표는 자동 분류 정확도 88% → 92%, 사용자 수동 수정률 11% → 7% 이하다. 사용자가 카테고리를 직접 고치는 비율은 전체 거래의 11%다 — [머니노트 자동 분류 기능 기획](../../../raw/moneynote/product-planning/머니노트-자동-분류-기능-기획-555555.md)
2. 88%는 두 시점에서 같은 값으로 기록됐다. 기획서는 2026년 3월 기준 88%, 2026-09-04 회의록은 8월 측정 88%다 (회의록은 원본 일부 누락) — [머니노트 자동 분류 기능 기획](../../../raw/moneynote/product-planning/머니노트-자동-분류-기능-기획-555555.md), [9월 릴리스 회의록 (v2.3)](../../../raw/moneynote/product-dev/9월-릴리스-회의록-v2.3-555555.md)
3. 개편 방식은 세 단계다. 가맹점명 정규화 사전에 은행별 축약 패턴을 등록하고, 규칙 매칭이 실패한 건만 통계 모델로 넘겨 2단계로 판정하며, 사용자가 카테고리를 고치면 해당 가맹점에 개인 규칙을 저장한다 — [머니노트 자동 분류 기능 기획](../../../raw/moneynote/product-planning/머니노트-자동-분류-기능-기획-555555.md)
4. 정확도는 주 1회 배치로 전체를 측정해 내부 대시보드에 기록한다 — [머니노트 자동 분류 기능 기획](../../../raw/moneynote/product-planning/머니노트-자동-분류-기능-기획-555555.md)
5. 범위 제외 항목은 사용자가 손으로 적는 현금 지출 입력 건과 해외 통화 거래다. 해외 통화는 환율 처리가 필요해 별도 기획으로 분리했다 — [머니노트 자동 분류 기능 기획](../../../raw/moneynote/product-planning/머니노트-자동-분류-기능-기획-555555.md)
6. 개인 규칙이 늘어나면 분류 지연이 커질 수 있어 사용자당 규칙 수 상한을 둔다 — [머니노트 자동 분류 기능 기획](../../../raw/moneynote/product-planning/머니노트-자동-분류-기능-기획-555555.md)
7. 오분류가 쌓이면 예산 리포트 신뢰도가 떨어져 프리미엄 해지 사유로 이어진다는 것이 개편 배경이다 — [머니노트 자동 분류 기능 기획](../../../raw/moneynote/product-planning/머니노트-자동-분류-기능-기획-555555.md)
8. 첫 동기화가 끝나면 최근 3개월 내역이 자동으로 분류된다. 자동 분류가 틀리면 사용자가 직접 고칠 수 있고 같은 가맹점은 이후 자동으로 반영된다 — [머니노트 서비스 소개](../../../raw/moneynote/product-description/머니노트-서비스-소개-555555.md)
9. 규칙 매칭 실패의 원인 중 하나는 가맹점명이 축약되어 들어오는 은행이다. 목록에서 달빛은행 비고가 "가맹점명이 축약되어 온다", 들녘은행 비고가 "가맹점명 필드가 비어 오는 경우가 있다" 다 — [머니노트 자동 분류 기능 기획](../../../raw/moneynote/product-planning/머니노트-자동-분류-기능-기획-555555.md), [은행 연동 지원 목록](../../../raw/moneynote/product-description/은행-연동-지원-목록-555555.md)
10. 폴링 결과는 큐에 넣고 분류기가 순서대로 처리한다. 분류기 지연이 폴링을 막지 않게 한 결정이다 — [거래내역 동기화 파이프라인](../../../raw/moneynote/product-dev/거래내역-동기화-파이프라인-555555.md)
