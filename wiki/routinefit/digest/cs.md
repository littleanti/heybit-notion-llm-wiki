## 핵심 사실

1. 환불 응대 기준은 결제 후 7일 이내 요청은 전액 환불, 7일이 지난 요청은 이용 일수를 일할 차감한 금액 환불이다. ⚠ 법무 규정은 14일이라 충돌한다 → [충돌 · 미확정](../conflicts.md) — [환불 처리 응대 가이드](../../../raw/routinefit/cs/환불-처리-응대-가이드-555555.md) (2026-08-30)
2. 환불 응대 절차는 결제일과 결제 경로 확인(스토어 영수증 화면 요청 가능) → 기한 판정 → 일할 차감액 안내 후 동의 → 스토어 처리 건은 스토어 절차 안내 및 티켓 기록이다. 금액을 먼저 확정해서 말하지 않는다 — 일할 차감액은 결제 경로별로 다르게 계산된다 — [환불 처리 응대 가이드](../../../raw/routinefit/cs/환불-처리-응대-가이드-555555.md)
3. 계정 삭제 요청은 앱 내 탈퇴 경로를 먼저 안내하고 대행 요청은 본인 확인 후 처리한다. 구독이 남아 있으면 탈퇴와 구독 해지가 별개라고 알리고 해지를 먼저 안내한다 — [계정 삭제 요청 응대](../../../raw/routinefit/cs/계정-삭제-요청-응대-555555.md) (2026-07-11)
4. 계정 삭제 응대에서 안내하는 "탈퇴 후 30일 보관" 문구는 원본이 스스로 CS 관행 문구이며 근거 문서가 없다고 밝히고 있다. 즉시 삭제 요청은 처리 가능 여부 확인 중이라고 답하고 티켓을 법무로 넘긴다 — [계정 삭제 요청 응대](../../../raw/routinefit/cs/계정-삭제-요청-응대-555555.md)

## 진행 중 · 초안

- 알림이 안 와요 응대 (초안) — 기기 알림 권한과 앱 내 알림 설정 확인 → 절전·방해 금지 모드 확인 → 앱 재설치나 기기 복원 여부 확인(앱을 한 번 열면 발송 토큰이 갱신된다) → KST 발송 기준 안내 → 2026-08-19부터 2026-08-21 사이 iOS 건은 서버 장애로 확인됐고 조치 완료 안내 순서다. 2026-08 장애 회고의 할 일로 신설된 문서다 — [알림이 안 와요 응대](../../../raw/routinefit/cs/알림이-안-와요-응대-555555.md) (2026-09-02)
- 2025 CS 응대 원칙 (meta 없음) — 첫 답변 24시간 내, 확인된 사실만 말하기, 금액·기한은 문서에 적힌 근거로만 답하기, 사과보다 다음 조치 먼저 적기, 같은 문의 3회 이상이면 응대 문서 작성·수정 5개 원칙이다. 원본이 "환불 기한처럼 지금과 다른 기준이 섞여 있다" 고 밝히면서도 "원칙 자체는 지금도 응대 교육에서 쓴다" 고 적고 있다 — [2025 CS 응대 원칙](../../../raw/routinefit/cs/2025-CS-응대-원칙-666666.md) (2025-11-20)
